📌 使用说明 ▸

数据来源：各竞品站 Shopify 公开接口 /products.json 全量抓取，与监控系统基线快照一致（快照时间见顶部）。
币种：各站原生货币不同，工作台内价格统一折算为 USD，便于横向比价；表中同时显示原生价与各站币种。
图片墙：每风格精选代表作，点击图片或品名直达源站商品页；图片加载失败会显示占位卡，不再空白。
站点管理：顶部「🧩 站点管理」可联网抓取任意 Shopify 竞品站（填域名 → 抓取 /products.json 全量分页 → 自动归一化 + 风格/材质分类并合并进当前视图），也可删除任意站点；增删结果存在本地浏览器，刷新保留。
API 模型调研：点「⚙️ API 模型调研配置」填入 OpenAI 兼容的 Base/Key/模型（默认 SillyDream），添加站点后会用模型对商品做风格/材质分类；未填 Key 时自动降级为关键词规则分类。Key 仅存本地浏览器。
交互：上方「数据源」可一键切换不同竞品组合（整页重渲染，星标本地保留）；筛选、排序、分页、分析卡联动均基于事件委托，点击分析卡可下钻筛选商品表。
🔎 数据真实性：
· 真实字段（源站直接抓取，可信）：商品名称 / 价格 / 图片 / 商品链接 / 文字详情，均来自目标站 Shopify /products.json；联网抓取时还会校验返回确为合法商品数组且归属所填域名（防代理篡改/串站）。
· 推断字段（本工具生成，仅供参考、需核实源站）：风格 / 材质 / 品类 由关键词规则或 AI 模型判断，可能不准。每条记录带来源角标 —— ✓ 基线 预置快照、≈ 规则 关键词规则、🤖 AI推断 模型生成；AI 推断项在详情页可一键「✎ 改用规则分类」消除幻觉。
· 可溯源：点击任意商品图片/品名/↗ 均可跳转源站商品页核验；站点管理面板标注每站来源（📸快照 / 🌐联网·日期）。
